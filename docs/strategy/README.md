## Canonical strategy sources

## Rule

A strategy's canonical folder owns its specification, formulas, design, execution semantics, risk semantics, validation methodology, UI, recovery ledger, and traceability.

Shared documents such as `docs/STRATEGIES.md` are indexes/descriptions. They are not authoritative for strategy mathematics.
