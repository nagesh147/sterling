# Start here

1. Open this folder as an Obsidian vault: `docs/obsidian`
2. Settings → Core plugins → enable **Daily notes** + **Templates**
3. Daily notes:
   - New file location: `daily`
   - Template file location: `templates/Daily`
   - Date format: `YYYY-MM-DD`
4. Templates folder: `templates`
5. Optional: install **Obsidian Git** (community plugins)
