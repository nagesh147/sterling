# Sterling Obsidian Vault

## Purpose
- Human notes, architecture decisions, daily notes
- Graphify export target (`graphs/`)
- Backlinks + visual graph for project knowledge

## Folders
- `daily/` — daily notes (use template)
- `architecture/` — ADRs, design decisions
- `graphs/` — Graphify exports / HTML / summaries
- `templates/` — note templates

## How to open
1. Install Obsidian
2. Open folder as vault: `.../Sterling/docs/obsidian`
3. Enable core plugin **Templates** (or Templater community plugin)
4. Set template folder to `templates`
5. Optional: Obsidian Git (see below)
