a)

Overview
i) The TrueData API provides Real Time streaming data via TCP while the historical data is provided
via REST. A client would need to connect to the respective TCP port for which they wish to receive
the real time data. In case historical data is required, then the client would need to login to the REST
service using the same login details and obtain the authentication token (bearer token) which would
be needed for each subsequent request.
